# CAULCATOR PROJECT
# This is a simple Calculator Project designed to get a better understand to the concepts of Graphical User Interface (GUI) development.

## Project Structure

- **Functionality** – Handles the calculation logic using a switch statement for basic arithmetic operations (+, -, *, /). It throws an exception for invalid operation.
- **GUI** – Implements the graphical interface and connects user input with the calculation logic.
- **Main** – Entry point of the application.

## What have I learned ?

- Key concepts about GUI.
- How to use Exception to handle invalid inputs.
